One system, many scales.

The interaction takes inspiration from these original works:

  • Brendan Bycroft’s LLM Visualization — a whole-model view that stays connected to its internals.
  • Transformer Explainer — open up an operation and inspect the values flowing through it.
  • Bartosz Ciechanowski’s Mechanical Watch — slow down a mechanism to see cause and effect.

This machine is an original, deliberately small teaching model. Lines show control and data dependencies; the kernel subsystems are software running on the CPU, not extra processors. Event durations are illustrative.

For the actual mechanisms: OSTEP, MIT xv6, and the primary source linked inside each component.

Keyboard: Tab to a component, Enter to open it. Escape returns to the whole machine. Every event can be scrubbed backward. Reduced-motion preferences are respected. All page assets are included in this file.
